# Excel 拆分与合并

> 篝火出品 · 收录于篝火 App 应用区

按列拆成多个文件（如按门店），多表合并

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/excel-split-merge/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `excel-split-merge_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `excel-split-merge_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `excel-split-merge_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

**拆分**（比如把全部门店的销售表按门店拆开）：
1. 把表格拖进窗口，支持 .xlsx 和 .csv；旧版 .xls 请先另存为 .xlsx。
2. 「要做什么」选「拆分」。「按哪一列拆」填表头名（例如 `门店`），也可以填列字母 `B`。
3. 点「开始处理」，每个不同的值生成一个文件，文件名是「原文件名-值」，每个文件都带表头。
4. 也可以选「每个工作表一个文件」，把一个工作簿里的多个工作表分别存成文件。

**合并**（比如把各门店交上来的表合成一张）：
1. 把要合并的表格一起拖进窗口。
2. 「要做什么」选「合并」。默认把所有行上下拼成一张表：表头按名称自动对齐，列的顺序不同也没关系，并且多一列「来源文件」。
3. 也可以选「每个文件一个工作表」。
4. 点「开始处理」，读完后自动生成「合并结果.xlsx」。

**其他说明**
- 表格上方有标题行时，把「表头在第几行」改成实际行号。
- CSV 自动识别 UTF-8 / GBK 编码，导出的 CSV 带 BOM，用 Excel 打开不乱码。
- 以 0 开头的编号、超过 15 位的订单号会保留原样，不会被转成科学计数法。
- 全部在本机完成，不联网、不上传。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 拖入 `samples/十月销售.xlsx`，选「拆分」，列填 `门店`，开始处理 | 生成 3 个文件：`十月销售-武汉光谷店.xlsx`、`十月销售-武汉汉街店.xlsx`、`十月销售-长沙五一店.xlsx`，每个 10 行数据加表头；订单号保持文本 |
| 拖入两个示例文件，选「合并」，开始处理 | 生成 `合并结果.xlsx`，共 32 行，第一列是「来源文件」。列顺序按先处理的那个文件，另一个文件的列按表头名对齐。九月 CSV 的列顺序虽然不同，数据也会落在对应的列下 |
| 列填 `城市` | 列表里显示失败，原因是「找不到列「城市」，表头是：日期、门店、商品、金额、订单号」 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
